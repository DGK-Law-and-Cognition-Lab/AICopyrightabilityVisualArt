# Study 4 changelog

The edit history of the Study 4 source files. The source files themselves carry none.

## 2026-10-08

Added the analysis pipeline, built to the registration `Docs/Preregistration/AsPredicted/Study4_AsPredicted.md`. The registration keeps the nine questions of the AsPredicted form and was registered on the Open Science Framework (OSF) on 8 October 2026, as part of an Open-Ended Registration in project https://osf.io/u3d69.

- `Study4_01_Quant.Rmd`: builds the long data from the two exports with the shared R helpers (`read_qualtrics_pair()`, `exclusion_flow()`, `read_item_scales()` and `reshape_ratings_long()`, which scores each rating by its position on the answer scale); takes each source's time from the six image slots; applies the five exclusion steps of registration question 6, the last of them the validity rule, and stops unless every registered count matches; and writes `study4_long_with_text.csv`. It then fits the registered linear mixed model on each measure, `rating ~ label * source_time * modification + (1 | id) + (1 | source)`; runs the fifteen confirmatory tests with Holm's correction and reads H1, H2 and H3 from them; writes the estimated marginal means; checks each verdict of the twelve difference tests with a cumulative-link model; runs the three secondary analyses of question 8 that need only the ratings; and records fit status, the session and a run manifest.
- `Study4_02_Text.ipynb`: measures the justifications with the shared module `shared/python/study_text.py` on a slice that holds no label, no source time and no rating, with the text seed 20260903 set through `set_text_seed()`, and checks that the module's rules equal Study 1's deposited `tables/text_rules.txt` and its SHA-256.
- `Study4_03_Integration.Rmd`: joins the text measures to the ratings and the label; runs the two registered creativity checks with `shared/R/text_checks.R`, with the second work (the source and modification pair) as the stimulus; refits the registered model without the Human-arm participants whose justifications are read as stating that a machine made the work, and sets each test's verdict beside its verdict on every participant; and runs the three exploratory descriptions the registration names.
- `README.md` and this file.

The blind switch (`UNBLIND_STUDY4`, FALSE by default) shuffles three labels with seed 20260421, before any summary or model: the Human and AI label across participants, the source times across each participant's six sources, and the modification levels across the three second works made from each source. The integration file also shuffles the ratings within each question and answer scale. A blind run writes its tables to `tables/blind_run/`, and its long data and its HTML reports to `blind_run/`.

Checked in blind mode only. Both R files were knitted in this folder with `UNBLIND_STUDY4` unset, through `rmarkdown::render()` with `output_dir = "blind_run"`, so every output went to `blind_run/` and `tables/blind_run/`. The notebook was run in place with the `python312` kernel.

- `Study4_01_Quant.Rmd` reproduced every registered count: 140 records, then 133 after the preview records, 125 after the unfinished ones, 119 after the seriousness item, 119 after the arithmetic check (no blank answer reached it) and 117 after the validity rule, with 62 in the AI arm and 55 in the Human arm. All 119 records before the validity rule had a condition and the correct task answer. The validity rule removed exactly the two records the registration names: `R_3SPOPWqijqK09xf`, which rated all ten sources, and `R_6mZWuqtRNco0jiF`, which names 1NonFigure in two slots and states 2, 3 and 1 sources at less than 1 hour, 10 hours and 100 hours. The data hold 6,318 justifications; the two six-point items hold 140 ratings and are left out, leaving 6,178 analysed ratings. Every answer was scored. All three registered linear mixed models and all three cumulative-link models converged, none singular. Every registered table was written with the expected rows: 15 confirmatory tests, 12 hypothesis readings, 12 cumulative-link checks, and 9, 9 and 3 rows for the three secondary analyses. The report opens with the blind sentence, and the run manifest lists all 21 outputs as written.
- `Study4_02_Text.ipynb` read `blind_run/study4_long_with_text.csv`. All six data files passed the column contract and each file keyed by response covers exactly the 6,318 responses. The embedding model loaded from the local copy.

Both registered checks ran with status ok. All 33 mixed models converged.
