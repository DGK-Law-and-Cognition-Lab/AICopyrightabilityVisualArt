# Study 3 changelog

The edit history of the Study 3 source files. The source files carry none themselves.

## 2026-10-08

The pipeline was checked against every commitment in the registration, and the blind run was made again from the current code. No outcome has been modelled or summarised on the real labels.

- Later on 7 October, after the entry below, `Study3_03_Integration.Rmd` gained the blind shuffle of the ratings within each question. Both R Markdown files gained the check that stops a blind run whose report would leave `blind_run/`. The blind outputs on disk had not been made again after those changes. The integration outputs in `tables/blind_run/` and its report in `blind_run/` therefore came from a run without the rating shuffle. In that run the rating-from-words check, the lasso word weights, and the affect and topic models, which take the rating as a predictor, related the words to the real ratings. Those files were moved out of the Study 3 folder, and every file in `blind_run/` and `tables/blind_run/` now comes from the current code.
- The registration fixes 20260421 as the seed of every resampling and shuffling step. The stability rule of the topic model refits the model on ten random subsets of the participants, and those subsets were drawn with the seeds 0 to 9, the defaults of the shared module. `Study3_02_Text.ipynb` now calls `study_text.set_text_seed(20260421)` before the first fit, so the ten refits use 20260421 to 20260430 and the final topic fit and the grouping of the agreement check use 20260421. The seeds are recorded in `tables/study3_text_environment.csv`. With these seeds the stability rule chooses five topics for creativity, where it chose seven before, and four for effort, as before. The word-list measures, the word counts, the vocabulary, the content-word lists and the word ratings are byte for byte the same.
- Both R Markdown files also stop an unblinded run whose report would be written to `blind_run/`. The README no longer suggests unblinding by editing the first line of the files, because the `knit:` line that chooses the report folder reads the environment variable and not that line.
- Validation, blind mode only. `Study3_02_Text.ipynb` was run in place. `Study3_01_Quant.Rmd` and `Study3_03_Integration.Rmd` were knitted in a scratch copy of the Study 3 folder, with the exports and the shared helpers read from their usual places, and their blind outputs were copied into `blind_run/` and `tables/blind_run/`. The exclusion flow and every count the registration states hold, and every registered table has its expected rows. The registered models and the cumulative-link models converged. The random-slope refits did not estimate all their variance terms, so the slope requirement was waived, and the decision table says why. Each report opens with its blind banner, every run manifest matches the files beside it, and no output names a folder particular to one machine. A blind run with its report sent anywhere but `blind_run/` stopped in its first chunk and wrote nothing. A blind fit says nothing about the real one.

## 2026-10-07

The Study 3 pipeline is built to its registration, `Docs/Preregistration/AsPredicted/Study3_AsPredicted.md`, and run blind. The registration has not been submitted, so no outcome has been modelled or summarised on the real labels.

- `Study3_01_Quant.Rmd` reads the Values and Labels exports and the survey file through the shared helpers, applies the four registered exclusion steps in order (100 records to 96, 94, 87 and 85), scores each rating by its position on the answer scale, and attaches each image's stated time from the `Image{k}` and `Image{k}_Time` fields. It stops unless the flow and every count the registration states hold: 43 Human and 42 AI participants, 1,530 justifications, 1,525 scored ratings, three participants with 17 recorded ratings, and the two `1FigureEff` answers with a code the final survey does not offer, which are scored NA and logged. It fits the registered model on each rating with sum-to-zero contrasts, runs the type III F tests with Satterthwaite degrees of freedom and the Holm correction over the six, gives the estimated marginal means, the Human minus AI gap at each time and the 100 hours minus under 1 hour contrast, runs the equivalence test of the 100-hour gap at plus or minus 0.224 in the registered model and in the random-slope refit, applies the three-way decision rule, checks each Holm verdict with a cumulative-link mixed model, and writes `tables/study3_time_contrast_for_study5.csv` for Study 5's editing-time bound.
- `Study3_02_Text.ipynb` measures the justifications with the shared module on a blind slice of six columns and writes the six data files to `nlp/` and the rules, checksum, grounding notes, topic tables, environment and manifest to `tables/`, all with the `study3_` prefix. It checks that the module's rules, written out for Study 1, equal Study 1's deposited `tables/text_rules.txt` and its SHA-256, and that Study 3's rules text differs from Study 1's only in the title and response-count lines. It was run in place.
- `Study3_03_Integration.Rmd` joins the measures to the ratings, the source and the stated time, runs the two registered text checks on both ratings through `shared/R/text_checks.R`, and runs the exploratory items the registration names: comparisons built on the word lists, word pleasantness and concreteness, topics, and the words that carry the rating prediction.
- The blind switch is `UNBLIND_STUDY3`, FALSE by default. In a blind run the source labels are shuffled across participants and the stated-time labels within each participant across that participant's images, both with seed 20260421, right after the data are built. Stated time varies within each participant, so shuffling source alone would have left the stated-time effect and the Study 5 contrast computed on real labels. Every output of a blind run goes to a `blind_run/` subfolder of the folder its real counterpart goes to, each report opens with a sentence saying nothing in it is a result, and the Study 5 contrast table is marked not usable.
- Validation, blind mode only: both R Markdown files were knitted in place with their reports sent to `blind_run/`, and the notebook was run in place. The exclusion counts match the registration, every table has its expected rows, the text contracts pass, and each report shows the blind banner. In the blind run the random-slope refits could not estimate all their variance terms, so the requirement was waived there. A blind fit says nothing about the real one.
