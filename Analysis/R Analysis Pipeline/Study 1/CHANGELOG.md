# Study 1 pipeline changelog

This file is the edit history of the source files in `Analysis/R Analysis Pipeline/Study 1/`: five R Markdown notebooks (`Study1_01_Quant.Rmd`, `Study1_03_Integration.Rmd`, `Study1_04_Robustness.Rmd`, `Study1_Figures.Rmd`, `Study1_Supplements.Rmd`) and one Python notebook (`Study1_02_Text.ipynb`). Entries are grouped by date, then by file, then by section, one line each. The source files themselves carry no edit history; everything of that kind lives here.

Where the older material is: byte-identical copies of the six files as they stood before the 2026-09-01 edits are in `_backup_2026-09-01_pre-audit-edits/`; files retired from the pipeline are in `_retired_2026-09-03/` (its README says why each one was retired); the review documents that prompted the edits, and the earlier changelog they produced, are in `_internal_notes/`. Section numbers refer to the headings inside each file as they stood on the date of the entry.

A note on a few terms used throughout. A mixed-effects model (LMM) is a regression that gives each participant and each image its own baseline, so that a participant's ten ratings are not treated as ten independent observations. Its random effects are those per-participant and per-image terms; a random-effects structure is singular when the fit has pushed one of their variances or correlations to its boundary, meaning the structure is richer than the data support. Type is the attribution manipulation (told the work is by a human artist, or by an image generator); TypeAI is the regression term carrying the machine-attribution effect; stimulus type is whether an image is figurative or non-figurative.
