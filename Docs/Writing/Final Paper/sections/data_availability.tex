The de-identified survey data of all five studies, the five survey files, the 30 stimulus images and the six registration documents are available at \url{https://anonymous.4open.science/r/AICopyrightabilityVisualArt-2B38/}, an anonymized copy of the lab's repository. De-identification emptied each record's IP address and location and replaced the participant number with a code, the same code for a person in every study; the ratings, the written explanations and every other answer are unchanged. Source data are provided with this paper: every value plotted in the figures, with the analysis table, row and column it comes from, is in \texttt{Docs/Writing/Final Paper/figures/plotted\_values.csv} in the same repository. The registrations are on the Open Science Framework at \url{https://osf.io/u3d69/overview?view_only=be795b275c3548428d74457df31a4159}. The two published word-norm datasets used in exploratory analyses are not redistributed and are available from their authors.\cite{warriner2013norms,brysbaert2014concreteness}
