% Code availability: the analysis code in the same repository as the data.
The analysis code is available at \url{https://anonymous.4open.science/r/AICopyrightabilityVisualArt-2B38/}. It holds the R and Python notebooks for each study and for the cross-study analyses, the shared text module that holds the eight word lists, and the image check, with the tables and figures that the code wrote and run records that give each file's checksum, a fingerprint of its exact bytes. It also holds the manuscript's sources and the scripts that write every number, table and figure in this paper from those tables, recording the table, row and column behind each number and plotted value. The repository keeps the project's folder layout, so every path in the code works as it stands, and its README gives the order in which to run the notebooks. Three pretrained models come from Hugging Face, a site that hosts trained models: all-mpnet-base-v2, DINOv2 and CLIP. The image check fetches the two image networks at fixed versions; the text code loads the sentence-embedding model from a copy on the computer, revision e8c3b32 here.
