{\raggedright\scriptsize \emph{Equivalence test}: two one-sided tests of whether the difference lies inside $\pm$\SourceBound{} points, half of Study~1's label penalty on the creativity of originals (\SOneHOneCreatDiffPrecise; 95\% confidence interval \SOneHOneCreatLo{} to \SOneHOneCreatHi). It passes when the 90\% interval lies wholly inside the bound. A pass means the effect is small, not that it is zero; a fail means only that it is not shown to be small. \emph{Two-sided test}: whether the difference is zero. \emph{Holm's correction} raises each $p$-value in a set of tests so that the chance of any false positive in the set stays at .05. None is the original shown again unchanged, where ratings sit near the floor of the scale. Editing hours are the hours stated for the hand edit (Study~5). Study~4's registration gives no wording for its tests at each level; `inside the bound' marks a passed equivalence test. \textsuperscript{a}Description only; Study~2's verdict rests on the equivalence test. \textsuperscript{b}The label's $F$ test, a term outside Study~4's registered set of tests (it asks whether the label changes the mean rating), shown as context. \textsuperscript{c}Not shown in the registered refit without the \SFourMachineMadeN{} Human-label participants who wrote that a machine made the work (Holm $p$~\SFourEssPenaltyPHolmRefitPrecise). \textsuperscript{d}The interval's upper end is \SFiveCreatPenaltyDramaticHiNinetyPrecise, just outside the bound.
