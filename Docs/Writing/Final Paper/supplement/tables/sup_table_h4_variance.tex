The two ratios come from two fits with different residual structures. The between-participant ratio is from a crossed mixed model with participant and image intercepts, the participant variance free by arm and one residual variance shared by the arms. The residual ratio is from a second model in which the participant and the residual variances both differ by arm but which has no image intercept, so its residual also holds the differences between images that image kind does not explain. Each test sets two positive variances equal, an interior point of the parameter space, so it is referred to an ordinary chi-square on one degree of freedom rather than to a boundary-corrected mixture; the deposited file records this in its own reference columns. Each ratio carries a 95\% interval from a participant-level percentile bootstrap, in which participants are resampled with replacement within each arm, duplicated participants are relabelled as distinct so the random-effects fit stays valid, both models are refit on every resample, and the interval is read from the 2.5th and 97.5th percentiles of the resampled ratios. H4 is supported on a dimension only if the participant ratio's interval lies wholly above 1 and the residual ratio's wholly below 1, a conjunction the h4\_supported column states, and H4 as registered requires it on both dimensions. This table shows the ratios, their intervals, the two tests and that verdict; the full table, with the arm-specific variances, the reference distribution of each test, the resample count, and the number of resamples whose refit failed or was singular, is deposited as tables/study1\_h4\_variance\_test.csv.}
